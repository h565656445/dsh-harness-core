# 权限边界

## 可自动进行

- 读取已授权的本地项目规则和状态；
- 生成 TaskContract、草稿、分析和验证报告；
- 在 Harness `runtime/` 创建任务实例和追加 Ledger；
- 执行只读检查与可逆的本地验证。
- 在用户显式批准启动后，让受监督 Worker 读取不可变任务包并返回结构化候选；模型工具使用只读沙箱，候选文件由 Harness 写入任务目录。

## 必须等待用户确认

- 发布、上线、公开发送或代表用户对外沟通；
- 删除、移动、归档、合并和不可逆覆盖；
- 付款、购买、充值、账号或权限变更；
- 正式章节、正式视频母版或正式规则晋级；
- 修改 Harness 核心权限、质量门或长期记忆规则。

审批只能解除合同中明确列出的动作，不能扩大整个任务的权限。
